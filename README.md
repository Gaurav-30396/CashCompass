# CashCompass

CashCompass is an Android expense tracking application built using Jetpack Compose.  
It helps users manage daily expenses, track spending habits, and organize financial records efficiently.

---

## Features

- Add and manage expenses
- Categorize transactions
- Budget setup functionality
- Clean and modern UI using Jetpack Compose
- Local database integration
- Expense tracking and history

---

## Tech Stack

- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
- Android Studio

---

## Project Structure

```bash
app/
 ├── data/
 ├── database/
 ├── ui/
 └── resources/
```

---

## Installation

1. Clone the repository

```bash
git clone https://github.com/Gaurav-30396/CashCompass.git
```

2. Open the project in Android Studio

3. Sync Gradle

4. Run the application on an emulator or a physical device
